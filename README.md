## 수정 방법

`index.html` 안의 `ITEMS` 배열에 아이템을 추가/수정하면 됩니다.

```js
{ no:"①", d:"1", cat:"c1", name:"아이템 이름",
  desc:"한 줄 설명", note:"짧은 메모",
  links:[ L.ali("https://s.click.aliexpress.com/e/..."),
          L.naver("https://naver.me/...") ] }
```

- `no` 표시 번호, `d` 검색용 숫자, `cat` 카테고리(`c1` 수납·정리 / `c2` 충전·거치 / `c3` 외장·보호 / `c4` 실내·기타)
- 여러 하위 품목은 `parts:[{name, sub, links:[...]}]` 사용
